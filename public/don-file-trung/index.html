Kết quả rà soát

Dung lượng dư là ước tính nếu giữ một bản mỗi nhóm. Chưa di chuyển hoặc xóa file nào.

Cách lấy danh sách file

Workflow “Read-only duplicate audit” trong repo backup-drive xuất các file drive.json, koofr.json và trash.json. Chọn đúng cloud tương ứng; mỗi file được phân tích riêng.

Hoặc dùng script scripts/duplicate_inventory.py trong repo web-home trên máy đã cấu hình rclone. Script chỉ liệt kê metadata và checksum, không tải nội dung hoặc xóa file.

Bước dọn có chọn sẽ được bổ sung sau: kiểm tra lại nội dung và bắt buộc giữ ít nhất một bản mỗi nhóm.
